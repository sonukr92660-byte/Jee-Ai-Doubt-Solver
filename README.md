# JEE AI DOUBT SOLVER

An AI-powered, multimodal educational web application built with Python and Streamlit to assist students with step-by-step solutions for IIT-JEE Physics, Chemistry, and Mathematics questions.

As a high school student recovering from an injury, I wanted to build something that could act as an instant, accessible academic guide for my peers when teachers aren't around.

## Features
- **Dual Input Interface:** Supports direct image uploads or real-time camera scanning for mobile and desktop devices.
- **Multimodal AI Analysis:** Integrated with the **Google Gemini-1.5-Flash** vision model to parse complex diagrams and handwritten or printed text.
- **Step-by-Step Logic Breakdown:** Delivers comprehensive explanations, highlights core formulas first, and builds structured logical steps to reach the final accurate answer.

## How to Setup Locally:
1. Clone the repository and install requirements: `pip install -r requirements.txt`
2. Run the application: `streamlit run app.py`

*Note: Requires a valid Google Gemini API Key entered directly into the secure UI input field to process solutions.*
